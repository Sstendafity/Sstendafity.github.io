MaleoScribe — audio to structured clinical documentation

Technical owner (PIC) · published, first author

An end-to-end LLM pipeline converting raw consultation audio into structured clinical documentation in the SOAPIE format, in Indonesian: ASR transcription and correction, structured extraction against a typed schema, and automated document generation, behind a production UI.

I designed and ran the evaluation, which became the published contribution. The argument was that a single accuracy number does not tell you whether a scribe is safe to deploy, so the protocol measured four things instead.

Word error rate
0.102character rate 0.072
Semantic similarity
0.978cosine, vs. reference
  • Semantic fidelity alongside raw error rate — a note can be word-imperfect and still clinically correct, or word-perfect and clinically wrong.
  • Domain-specific error — medical-term and entity error rates, scoring the words that actually matter separately from filler.
  • Noise robustness across controlled SNR levels. A clinic is not a quiet room.
  • Repeatability — output stability across repeated runs on identical input, because a scribe that returns a different note each time cannot be trusted with a medical record.

Designed with an explicit clinical safety boundary: the system summarises facts for physician review and does not diagnose.

Compliance auditing and anomaly detection

Isolation Forest + retrieval-augmented contextualizer · selected as a top-5 candidate in a national public-sector AI track

A system that flags irregularities in large, messy regulatory datasets. The anomaly model scores each record; the retrieval layer attaches the specific regulation it appears to violate — so a reviewer gets a reason, not an unexplained score they have to take on faith.

Shipped with the reviewer-facing application: risk-sorted audit queue, per-record deep dive, facility benchmarking and risk heatmaps. All personally identifying columns are dropped at load and never reach the cache; the analysis runs on anonymised identifiers, codes and aggregates.

Medical document extraction pipeline

Arbitrary medical PDFs → typed, de-identified, structured data

  1. Ingestion & triage — per-page classification into native-text vs scanned, using a structural text-quality score that rejects corrupt text layers, not just empty ones. Multiple table extractors run in parallel, each result recorded with its accuracy and bounding box.
  2. OCR — pluggable engines recover the scanned pages back into the same document representation.
  3. De-identification — rule-based patterns plus named-entity recognition tuned for Indonesian, redacting the text layer, table cells, and the OCR word bounding boxes so scanned images can be blacked out downstream.
  4. Structured extraction — LLM tool-use against a typed schema, run only on de-identified input.

Two decisions carried the design. Every phase reads and writes one intermediate representation carrying page and bounding-box provenance end to end, so any field in the final output traces back to the pixel it came from. And every dependency was chosen to be commercial-license-safe — the obvious PDF library was rejected on licence grounds. It ships with a batch audit tool that flags the pages needing human review before the output is trusted.

Adulterant detection in minced meat

Minced beef loses the morphological cues that make adulteration visible to the eye, which makes it a target for substitution fraud. Biomedical Signal Processing

KardiaQ — portable heart screening

Signal-Processing Developer · research initiative

Python pipelines to clean and analyse noisy, smartphone-acquired physiological time-series (seismocardiogram and phonocardiogram). The difficulty is that consumer-hardware recordings arrive with irregular sampling and heavy motion artefact, so the pipeline derives its own sample rate from the timestamps rather than trusting a nominal value, then bandpass-filters, denoises and detects beats.

Fiber-optic cardiac sensing

Singlemode–multimode–singlemode (SMS) fiber structure as the transducer

Optical sensing for non-invasive cardiac monitoring — far cheaper and simpler than the fiber Bragg gratings normally used for this, and immune to the electromagnetic interference that rules out electrode-based monitoring inside an MRI bore.

Seismocardiography with a PDMS enclosure — published

Cardiac vibration strains the fiber, changing its refractive index through the photoelastic effect and modulating transmitted optical power — a heartbeat read as an intensity signal on a simple power meter, with no spectrometer in the setup. The contribution was showing the sensor could be mechanically packaged without losing accuracy, validated against simultaneous ECG.

Fetal phonocardiography — national research grant

Sensor fabrication and characterisation across a full variant matrix: step-index, graded-index and coreless multimode sections at 3 cm and 4.5 cm, spliced between single-mode fiber and interrogated at 1550 nm. Each variant was tested on an acoustic rig replaying a public fetal heart sound database, so every one met identical, repeatable input. Signal chain: 30–70 Hz bandpass → discrete wavelet transform → Hilbert envelope → peak detection for S1/S2 identification.

Finding: the 3 cm coreless variant resolved S1 and S2 most clearly. Graded-index was markedly quieter, but its amplitude was too small to segment reliably — a real sensitivity-versus-noise trade-off, documented rather than smoothed over.
